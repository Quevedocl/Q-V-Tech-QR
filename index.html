Preguntas frecuentes

¿Qué diferencia hay entre estático y dinámico?

El estático guarda el destino dentro del dibujo y no cambia. El dinámico apunta a un enlace corto nuestro: si cambias el destino, el mismo código impreso lleva a la página nueva.

¿Qué pasa si pauso o borro un código dinámico?

Quien lo escanee verá un aviso de que no está activo. Puedes reactivarlo cuando quieras mientras no lo borres.

¿Cómo se miden los escaneos?

Cada visita al enlace corto suma un escaneo con fecha, tipo de dispositivo y país. No guardamos datos personales.

¿Puedo imprimirlo grande?

Sí, descarga el SVG. Prueba siempre el código con tu teléfono antes de imprimir.
